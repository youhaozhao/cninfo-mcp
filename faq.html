常见问题 ​

关于项目 ​

cninfo-mcp 是什么？ ​

cninfo-mcp 是一个开源的 MCP（Model Context Protocol）服务器。接入 Claude 等 AI 助手之后，助手可以在巨潮资讯网上检索公告、阅读年报和招股书正文、获取财务与股东数据，并在需要时下载 PDF。它面向 A 股投研场景，一共提供 8 个工具，见工具与配置参考。

cninfo-mcp 是巨潮资讯网的官方产品吗？ ​

不是。它是社区维护的开源项目，与巨潮资讯网的运营方深圳证券信息有限公司没有隶属、合作或授权关系。工具调用的是巨潮资讯网网页自身使用的查询接口，不是官方数据服务接口，可能随时变更、限流或停用。

巨潮资讯网是什么？ ​

巨潮资讯网（cninfo.com.cn）是中国证监会指定的上市公司信息披露网站，由深圳证券信息有限公司运营。沪、深、北三家交易所上市公司的公告和定期报告都可以在上面查到。

它和基于 AKShare、Tushare、BaoStock 的 MCP 服务器有什么区别？ ​

那几类服务器以行情和结构化数据为主。cninfo-mcp 读的是披露文件本身：公告、年报、招股书的正文，以及巨潮个股页上的财务和股东数据，不提供行情。两类工具可以同时接入，各取所长，详见 A 股 MCP 服务器怎么选。

收费吗？用的是什么许可证？ ​

不收费。项目以 MIT 许可证开源，源码在 GitHub。

安装与环境 ​

需要什么运行环境？ ​

只需要 Node.js 22.13 或更高版本。发布包自带全部依赖，安装时不会再拉取其他包。各客户端的写法见安装与配置。

需要 API Key、账号或 Python 吗？ ​

都不需要。服务器不需要、也不读取任何账号、Cookie 或密钥。从 3.0 版本开始也不再依赖 Python。

支持哪些 AI 客户端？ ​

任何支持 MCP（stdio 传输）的客户端都可以接入，例如 Claude Code、Claude Desktop、Cursor、VS Code、Codex CLI、Gemini CLI、Cherry Studio、Trae、OpenClaw、Cline 和 Windsurf。

支持 Windows 吗？ ​

支持 Windows、macOS 和 Linux。项目的持续集成会在这三个平台上安装发布包并运行离线自检。

在中国大陆以外能用吗？ ​

可以，只要所在网络能访问 cninfo.com.cn。可以先运行 npx -y @youhaozhao/cninfo-mcp probe 做一次联网自检。

npx 下载很慢怎么办？ ​

把 npm 切换到镜像源后再试：npm config set registry https://registry.npmmirror.com。

数据与范围 ​

覆盖哪些市场？ ​

公告检索覆盖沪、深、北交所上市公司（含 B 股）和港股公告，基金、债券可以按代码检索公告。定期报告列表、财务数据和公司数据支持沪、深、北交所上市公司，包括主板、创业板和科创板。

能查港股吗？ ​

港股公告可以检索：用 00700.HK 这样的代码，配合标题关键字。公告分类只适用于沪、深、北交所，港股请用关键字。定期报告列表、财务数据和公司数据不支持港股。

能查实时行情、K 线或技术指标吗？ ​

不能。cninfo-mcp 专注披露文件和基本面数据。需要行情时，可以搭配其他数据源的 MCP 服务器。

能对公告做全文检索吗？ ​

不能跨公告做全文检索：公告是按标题关键字检索的。读取单个文档时，可以用 read_document 的 query 参数在文档内按关键字定位。

财务数据是什么口径？能取多少期？ ​

get_financials 返回主要指标、利润表、资产负债表和现金流量表，每种报告期类型最多最近五期（上游只提供五期）。报表金额单位为万元，是巨潮个股页的精简口径（主要科目）；季报和半年报是年初至报告期末的累计值。需要完整科目时，请用 read_document 读报告原文。

数据准确吗？ ​

公告和报告是上市公司披露的原文。结构化数据可能与报告原文存在口径差异，重要数字请以披露文件为准。工具不对内容的准确性、完整性和时效性作任何保证。

扫描版的 PDF 能读吗？ ​

不能。部分早期公告是扫描件，没有文本层，无法读出正文，read_document 会在结果里给出提示。

使用 ​

股票要写代码还是简称？ ​

都可以。所有 stock 参数都接受 600519、000001.SZ、00700.HK 这样的代码，也接受 贵州茅台 这样的简称。北交所股票的新旧代码都可以用，例如 920185 和 835185 指向同一家公司。

读年报必须先下载吗？ ​

不需要。read_document 直接读取 PDF 正文，下载工具只在你想把文件留在本地时才用得上。读法见用 AI 读年报。

可以批量下载年报吗？ ​

可以。让 AI 调用 download_reports 并省略年份，就会下载一家公司全部年份的年报全文；多家公司可以逐家下载。请保持默认的并发限制，不要做高频或大批量抓取。详见年报下载。

下载的文件保存在哪里？ ​

默认保存在 ~/Downloads/cninfo-mcp，可以用环境变量 CNINFO_MCP_DOWNLOAD_DIR 修改。文件名是 代码_简称_标题_公告ID.pdf，目标文件已存在时不会重新下载。

为什么会遇到 403？ ​

巨潮资讯网用 403 表示限流：短时间内请求过多时会返回 403，并暂时封禁 IP。服务器对所有上游请求统一限速，被限流时会全局暂停一段时间再重试，通常等待片刻即可恢复。不建议调高 CNINFO_MCP_CONCURRENCY。

结果里的 complete 为 false 是什么意思？ ​

表示这次结果不完整：部分分页、部分数据集或部分文件失败了。已取得的内容照常返回，同时附带 warnings 或 errors 说明缺了什么。稍后重试通常可以补齐。

合规与安全 ​

用它获取数据合规吗？ ​

本项目不托管、不转发任何报告内容，所有数据都由你的机器直接从巨潮资讯网获取。网站页脚标注“深圳证券信息有限公司 版权所有”，报告文件由各上市公司披露；下载后的使用方式，尤其是再分发和商业用途，请自行确认是否合规。使用时请保持默认并发，不要做高频或大批量抓取。

它会访问哪些网站、写哪些文件？ ​

只访问 https://www.cninfo.com.cn（查询与数据）和 https://static.cninfo.com.cn（文档）。只有两个下载工具会写用户可见的文件，并且只写入下载根目录；除此之外，服务器只写自己的缓存目录。详见安全边界。

输出可以当作投资建议吗？ ​

不可以。工具只负责检索、读取和整理公开披露信息，不构成投资建议。
