Frequently asked questions ​

About the project ​

What is cninfo-mcp? ​

cninfo-mcp is an open-source Model Context Protocol (MCP) server. Once connected, an AI assistant such as Claude can search company announcements, read annual reports and prospectuses, fetch financial and shareholder data, and download PDFs from CNINFO. It is built for research on China A-shares and provides eight tools, listed in the tools reference.

What is CNINFO? ​

CNINFO (巨潮资讯网, cninfo.com.cn) is the disclosure website for listed companies designated by the China Securities Regulatory Commission, operated by Shenzhen Securities Information Co., Ltd. Announcements and periodic reports of companies listed in Shanghai, Shenzhen and Beijing are published there.

Is cninfo-mcp an official CNINFO product? ​

No. It is a community-maintained open-source project with no affiliation, partnership or licence from Shenzhen Securities Information Co., Ltd. It calls the query endpoints that the CNINFO website itself uses, not an official data service, so those endpoints can change, be rate-limited or be withdrawn at any time.

Is it free? What is the licence? ​

Yes, it is free. The project is MIT-licensed and the source is on GitHub.

Installing ​

What do I need to run it? ​

Node.js 22.13 or newer. The published package is self-contained and pulls in no other packages at install time. See Install and configure.

Do I need an API key, an account or Python? ​

No. The server does not need, and never reads, accounts, cookies or secrets. Since version 3.0 it no longer depends on Python.

Which AI clients does it work with? ​

Any client that supports MCP over stdio, including Claude Code, Claude Desktop, Cursor, VS Code, Codex CLI, Gemini CLI, OpenClaw, Cline, Windsurf and Cherry Studio.

Does it work on Windows? ​

Yes. Windows, macOS and Linux are supported, and the project's continuous integration installs the published package and runs the offline self-test on all three.

Does it work outside mainland China? ​

Yes, as long as your network can reach cninfo.com.cn. Run npx -y @youhaozhao/cninfo-mcp probe to check.

Data and coverage ​

Which markets are covered? ​

Announcement search covers companies listed in Shanghai, Shenzhen and Beijing (including B shares) and Hong Kong announcements; funds and bonds can be searched by code. Report listings, financial data and company data cover Shanghai, Shenzhen and Beijing listings, including the main boards, ChiNext and the STAR Market.

Are the filings available in English? ​

Almost all filings on CNINFO are in Chinese. Your assistant reads the Chinese text and can answer in English with page references. Where a company also files an English version of a report, list_reports returns it when include_variants is set.

Do I have to write prompts in Chinese? ​

No. Ask in English and identify companies by stock code, such as 600519 or 000001.SZ. The tools also accept Chinese short names (贵州茅台), and assistants usually resolve well-known English company names to the right code on their own.

Does it provide stock prices or price history? ​

No. cninfo-mcp focuses on disclosures and fundamentals. For quotes and technical indicators, pair it with an MCP server built on a market-data source.

Can it search the full text of all announcements? ​

No. Announcements are searched by title keyword. Inside a single document, read_document can locate keywords with its query argument.

How many periods of financial data are available? ​

get_financials returns key ratios, the income statement, the balance sheet and the cash flow statement for up to the five most recent periods of one period type, which is what the upstream source offers. Statement amounts are in units of 10,000 CNY (万元). Quarterly and semi-annual figures are cumulative year-to-date.

How accurate is the data? ​

Announcements and reports are the documents the listed companies filed. The structured data is the condensed view shown on CNINFO's company pages and can differ in definition from the full statements, so check important figures against the filing itself. The tool makes no guarantee of accuracy, completeness or timeliness.

Using it ​

Do I need to download a report to read it? ​

No. read_document reads the PDF text directly. The download tools are only for keeping a local copy. See Read Chinese annual reports with AI.

Can I download annual reports in bulk? ​

Yes. Ask the assistant to download a company's annual reports without naming a year and download_reports saves every year available. Keep the default concurrency and do not use the tool for high-frequency or large-scale scraping. See Download Chinese annual reports.

Why do I get HTTP 403? ​

CNINFO uses 403 to signal rate limiting: too many requests in a short time are answered with 403 and a temporary IP block. The server rate-limits all upstream requests and pauses globally before retrying, so it usually recovers by itself.

What does complete: false mean in a result? ​

The result is partial: some pages, datasets or files failed. What was retrieved is still returned, with warnings or errors describing what is missing. Retrying later usually fills the gap.

Compliance and safety ​

Is it compliant to retrieve data this way? ​

The project does not host or relay any report content: your own machine fetches everything directly from CNINFO. The website's footer states that its content is copyrighted by Shenzhen Securities Information Co., Ltd., and the reports themselves are disclosed by the listed companies. How you use downloaded files, especially redistribution and commercial use, is for you to verify.

Which hosts does it contact and which files does it write? ​

It only contacts https://www.cninfo.com.cn (queries and data) and https://static.cninfo.com.cn (documents). Only the two download tools write user-visible files, and only inside the download root; apart from that the server writes to its own cache folder.

Is the output investment advice? ​

No. The tool retrieves and organises public disclosures. It is not investment advice.
