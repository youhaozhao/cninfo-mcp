CNINFO MCP serverLet your AI readChina A-share filings

cninfo-mcp is an open-source MCP server for China-market research. It lets Claude, Cursor and other assistants search company announcements, read annual reports and prospectuses, and pull financial and shareholder data from CNINFO, the CSRC-designated disclosure site for companies listed in Shanghai, Shenzhen and Beijing.

Claude Code

$claude mcp add cninfo -- npx -y @youhaozhao/cninfo-mcp

Node.js 22.13+ is all you need. No Python, no API key.

How it works

Install it, then just ask

No tool names or parameters to remember. Ask in plain language, in English or Chinese, and the assistant picks the tools and chains the calls. Filings are in Chinese; the assistant can read them and answer in English.

  • What does Kweichow Moutai's 2025 annual report say about industry trends for the year ahead?

    list_reports→read_document

    Finds the report, locates the section by keyword and reads only those pages.

  • Compare CATL's revenue, net profit, operating cash flow and ROE over the last five years

    get_financials

    One call returns key ratios, the income statement and the cash flow statement for five periods.

  • Which ChiNext companies published earnings forecasts in the past month?

    search_announcements

    Leave out the company for a market-wide search filtered by category, board and date.

  • Download the IPO prospectus of 688981 (SMIC)

    download_reports

    Saves the PDF to the download folder, named by code, company and title.

  • How have Moutai's top ten shareholders and shareholder count changed recently?

    get_company_data

    Several datasets in one request: top holders, shareholder count, dividends, pledges and more.

  • What did institutional investors ask CATL in its latest investor meetings?

    search_announcements→read_document

    Searches investor-relations activity records, then reads the record itself.

Tools

Eight tools for the whole research loop

Find the company, find the filing, read it, pull the numbers, keep a copy.

Find and search

search_securitiesRead-only
Find a security by code, Chinese short name or pinyin initials.
list_reportsRead-only
List annual, semi-annual and quarterly reports or prospectuses with title, disclosure date and PDF URL.
search_announcementsRead-only
Search announcements by company, title keyword, category, date and board. Market-wide when no company is given; also covers investor-relations records.

Read

read_documentRead-only
Read a filing as text: overview with table of contents, keyword search inside the document, or specific pages.

Structured data

get_financialsRead-only
Key ratios, income statement, balance sheet and cash flow statement for the five most recent periods.
get_company_dataRead-only
Company profile, top ten shareholders, shareholder count, dividends, pledges, lock-up expiries, margin trading, block trades and more: 15 datasets.

Download

download_reportsWrites to the download folder
Save periodic reports or prospectuses as PDF files.
download_documentsWrites to the download folder
Save specific announcements by URL.

Design choices

Built for research, not for scraping

  • Primary-source filings

    Data comes straight from CNINFO, the disclosure website designated by the China Securities Regulatory Commission. The assistant reads what the company actually filed and can cite the report and page.

  • Handles 200-page reports

    read_document returns the page count and table of contents first, then finds sections by keyword and reads page ranges. No need to load a whole PDF into context, or to download and upload it.

  • One command to install

    Node.js is the only requirement. No Python environment, API key, account or credits. The published package is self-contained and pulls in nothing else at install time.

  • Polite to the upstream site

    CNINFO answers bursts of requests with 403 and a temporary IP block. The server rate-limits every request globally, backs off when throttled and caches documents on disk.

  • Honest about partial results

    If some pages, datasets or files fail, what was retrieved is still returned and flagged complete: false, so a partial result is never presented as the full picture.

  • Clear boundaries

    It talks to two CNINFO hosts over HTTPS only, writes only inside its download folder, and needs no credentials. Every tool is annotated as read-only or writing.

Coverage

What it covers, and what it does not

In scope

  • AnnouncementsCompanies listed in Shanghai, Shenzhen and Beijing (including B shares) plus Hong Kong announcements; funds and bonds by code.

  • Periodic reports and prospectusesAnnual, semi-annual, Q1 and Q3 reports, and IPO prospectuses.

  • Document textPDF filings, and HTML for older announcements.

  • Structured dataFinancial ratios, three statements and 15 company datasets for Shanghai, Shenzhen and Beijing listings.

Out of scope

  • Real-time quotes and price history

  • Full-text search across announcements (search is by title keyword; keyword search works inside a single document)

  • Scanned documents without a text layer (some older filings)

  • English translations of filings: documents are in Chinese, and your assistant does the translating

For quotes and technical indicators, pair it with an MCP server built on a market-data source. For bulk or commercial data needs, see Is there a CNINFO API? →

Install

Connected in a minute

Works with any client that supports MCP over stdio. Here are the common ones.

$claude mcp add cninfo -- npx -y @youhaozhao/cninfo-mcp

Settings → Developer → Edit Config, add the block below and restart the app.

{
  "mcpServers": {
    "cninfo": {
      "command": "npx",
      "args": ["-y", "@youhaozhao/cninfo-mcp"]
    }
  }
}

Put this in ~/.cursor/mcp.json (global) or .cursor/mcp.json in a project.

{
  "mcpServers": {
    "cninfo": {
      "command": "npx",
      "args": ["-y", "@youhaozhao/cninfo-mcp"]
    }
  }
}
$code --add-mcp '{"name":"cninfo","command":"npx","args":["-y","@youhaozhao/cninfo-mcp"]}'
$codex mcp add cninfo -- npx -y @youhaozhao/cninfo-mcp

Cline, Windsurf, Cherry Studio and others: command npx, arguments -y and the package name, or import this JSON.

{
  "mcpServers": {
    "cninfo": {
      "command": "npx",
      "args": ["-y", "@youhaozhao/cninfo-mcp"]
    }
  }
}

To check that your machine can reach CNINFO, run the self-test:

$npx -y @youhaozhao/cninfo-mcp probe

FAQ

Before you start

Is cninfo-mcp an official CNINFO product?

No. It is a community-maintained open-source project with no affiliation, partnership or licence from Shenzhen Securities Information Co., Ltd., which operates CNINFO. It calls the query endpoints that the CNINFO website itself uses, not an official data service, so those endpoints can change or be rate-limited at any time.

Do I need an API key, an account or a subscription?

No. cninfo-mcp is MIT-licensed and only needs Node.js 22.13 or newer. It does not need Python and never reads accounts, cookies or secrets.

Are the filings available in English?

Almost all filings on CNINFO are in Chinese. Your assistant reads the Chinese text and can answer in English, citing the page it read. Where a company also files an English version of a report, list_reports returns it when include_variants is set.

Which AI clients does it work with?

Any client that supports MCP over stdio, including Claude Code, Claude Desktop, Cursor, VS Code, Codex CLI, Cline, Windsurf and Cherry Studio.

Does it provide stock prices?

No. cninfo-mcp focuses on disclosures and fundamentals, such as announcements, periodic reports, prospectuses, financial statements, shareholder data and trading disclosures. For quotes and price history, pair it with an MCP server built on a market-data source.

How accurate is the data?

Announcements and reports are the documents the listed companies filed. The structured financial data is the condensed view shown on CNINFO's company pages and can differ in definition from the full statements, so check important figures against the filing itself. Nothing here is investment advice.
