巨潮资讯网有 API 吗？官方数据服务、爬虫与 MCP ​

简短的回答：有官方的数据服务，但它和大家在巨潮资讯网上浏览公告时用到的接口不是一回事。想从巨潮资讯网取数据，实际上有三条路，适合的场景各不相同。

方式是什么适合
官方数据服务深证信数据服务平台提供的数据接口稳定的批量取数、商业用途
网页接口（爬虫）巨潮资讯网页面自身调用的查询接口会写代码、需要自定义流程的研究
MCP 服务器cninfo-mcp 把查询、阅读和下载封装成 AI 可以调用的工具用 AI 助手做对话式的研究

官方数据服务 ​

巨潮资讯网的运营方深圳证券信息有限公司提供深证信数据服务平台，面向开发者和机构提供数据接口。使用前需要注册并申请接口权限，接口范围、调用额度和收费方式以平台公布的为准。

如果需要稳定、成规模地取数，或者用于商业产品，这是应该优先考虑的途径。

网页接口与爬虫 ​

在巨潮资讯网上搜索公告、筛选分类时，页面会向网站自己的查询接口发请求。很多开源爬虫和数据接口库用的就是这些接口。它们可以直接访问，不需要密钥，但有几个特点需要了解：

  • 非官方、无文档：接口是给网页用的，没有公开的说明，也没有稳定性承诺，可能随时变更。
  • 会限流：短时间内请求过多时，网站返回 403，并暂时封禁 IP。
  • 细节不少：按公司查询要先把股票代码换成网站内部的机构编号；公告列表每页最多 30 条，需要自己翻页；公告分类和板块各有一套编码；下载到的也可能不是 PDF，而是限流时返回的错误页面。
  • 定期报告要自己辨认：年报全文、摘要、英文版和更正公告混在同一个列表里，需要按标题规则区分。

自己写爬虫的好处是完全可控，适合有编程能力、需要自定义处理流程的场景。

MCP 服务器：cninfo-mcp ​

cninfo-mcp 用的同样是网页接口，但把上面这些细节都处理掉了，再包装成 8 个工具，交给 AI 助手调用：

  • 代码和简称都可以，自动解析到对应的公司，北交所新旧代码都认。
  • 所有请求统一限速，被限流时自动冷却重试；读过的文档缓存在本机。
  • 自动区分报告全文、摘要、英文版和修订版。
  • 直接读取 PDF 正文：给出目录，按关键字定位，按页读取。
  • 结果不完整时用 complete: false 明确标出。

它不是给程序调用的数据接口或 SDK，而是给 AI 助手用的工具。你用自然语言提问，助手决定调用哪些工具：

过去一个月创业板有哪些公司发布了业绩预告？

贵州茅台 2025 年年报里，管理层怎么看明年的行业趋势？

安装只需要一条命令，不需要 API Key，见安装与配置。

和网页接口一样的限制

cninfo-mcp 是社区维护的开源项目，不是巨潮资讯网的官方产品。它调用的接口可能随时变更、限流或停用，也不适合做高频或大批量的抓取。

怎么选 ​

  • 要把全市场的数据入库，或者用在商业产品里：用官方数据服务，或者商业数据库。
  • 要在自己的程序里取数：自己写爬虫，或者使用封装了相关接口的开源数据接口库；注意限流和合规。
  • 想让 AI 帮你查公告、读年报、对比财务数据：用 cninfo-mcp。
  • 需要行情、K 线和技术指标：巨潮资讯网不是行情数据源，见 A 股 MCP 服务器怎么选。

合规提醒 ​

无论用哪种方式，巨潮资讯网页脚都标注“深圳证券信息有限公司 版权所有”，报告文件由各上市公司披露。下载后的使用方式，尤其是再分发和商业用途，请自行确认是否合规。网站同时公布了免责声明，不担保信息的准确性和完整性，使用时请以网站公布的最新内容为准。
