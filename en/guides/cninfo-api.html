Is there a CNINFO API? ​

Short answer: there is an official data service, but it is not the same thing as the endpoints the CNINFO website uses when you browse announcements. In practice there are three ways to get data from CNINFO, and they suit different jobs.

RouteWhat it isGood for
Official data serviceData APIs offered by the operator of CNINFOStable bulk access, commercial use
Website endpoints (scraping)The query endpoints the CNINFO pages call themselvesCustom pipelines, if you write code
MCP servercninfo-mcp wraps search, reading and download as tools an AI assistant can callConversational research with an assistant

The official data service ​

Shenzhen Securities Information Co., Ltd., which operates CNINFO, runs a data service platform (深证信数据服务平台, in Chinese) with data APIs for developers and institutions. You need to register and apply for access; the available interfaces, quotas and pricing are whatever the platform publishes.

If you need dependable access at scale, or data for a commercial product, start there.

Website endpoints and scrapers ​

When you search announcements on cninfo.com.cn, the page sends requests to the site's own query endpoints. Many open-source scrapers and data libraries use the same endpoints. They need no key, but there are things to know:

  • Unofficial and undocumented. They exist for the website, come with no documentation or stability promise, and can change at any time.
  • Rate-limited. Too many requests in a short time are answered with HTTP 403 and a temporary IP block.
  • Full of details. Querying by company requires mapping the stock code to the site's internal organisation ID first. Lists return at most 30 items per page. Categories and boards have their own codes. A download may turn out to be an error page instead of a PDF when you are throttled.
  • Periodic reports must be told apart. The full report, its summary, the English version and correction notices sit in one list and have to be distinguished by title.

Writing your own scraper gives you full control and suits custom processing, if you are prepared to maintain it.

The MCP server: cninfo-mcp ​

cninfo-mcp uses the same website endpoints, handles those details, and exposes eight tools to an AI assistant:

  • Stock codes and Chinese short names both work and are resolved to the right company.
  • Every request is rate-limited globally, with automatic back-off when throttled, and documents are cached on disk.
  • Full reports, summaries, English versions and revised versions are told apart automatically.
  • PDF text is read directly: table of contents, keyword search inside the document, page ranges.
  • Partial results are flagged with complete: false.

It is not a data API or an SDK for your program. It is a set of tools for an assistant: you ask in plain language and the assistant decides what to call.

Which ChiNext companies published earnings forecasts in the past month?

What does the 2025 annual report of 600519 say about industry trends for the year ahead?

Installation is one command and needs no API key. See Install and configure.

Same limits as the website endpoints

cninfo-mcp is a community-maintained open-source project, not an official CNINFO product. The endpoints it calls can change, be rate-limited or be withdrawn at any time, and it is not suited to high-frequency or large-scale scraping.

Which one should you use? ​

  • Loading the whole market into a database, or building a commercial product: the official data service or a commercial data vendor.
  • Fetching data from your own program: write a scraper or use an open-source data library that wraps these endpoints, and mind the rate limits and terms.
  • Having an assistant find announcements, read annual reports and compare financials: cninfo-mcp.
  • Quotes, price history and technical indicators: CNINFO is not a market-data source. Use a market-data provider.

A note on terms ​

Whichever route you choose, CNINFO's footer states that the site's content is copyrighted by Shenzhen Securities Information Co., Ltd., and the reports are disclosed by the listed companies. Check for yourself whether your intended use, especially redistribution or commercial use, is permitted. The site also publishes a disclaimer that it does not warrant the accuracy or completeness of the information.
