Tools and configuration reference ​

This page is an English rendering of the Chinese reference, which is generated from the repository and is always current. It was last checked against version 3.0.0.

Every stock argument accepts a code or a Chinese short name: 600519, 000001.SZ, sh600519, 920185 (Beijing Stock Exchange, old and new codes both work), 00700.HK, 贵州茅台.

Find and search ​

search_securities ​

Find securities by code, short name or pinyin initials. Covers A and B shares in Shanghai, Shenzhen and Beijing, and Hong Kong stocks; funds and bonds are found by exact code.

  • query (required): a code, part of a name, or pinyin initials, such as 茅台, gzmt, 6005
  • limit (optional): number of results, default 10

list_reports ​

List a company's periodic reports or prospectuses.

  • stock (required)
  • report_type (optional): report type, default annual
  • year (optional): fiscal year of the report; for prospectuses, the disclosure year. Omit it for all years
  • include_variants (optional): also return summaries, English versions and other variants, default false

Values of report_type:

Each result has a kind:

Announcements about a report, such as a correction notice, are not reports and do not appear in the results.

search_announcements ​

Search announcements, newest first by default.

  • stock (optional): code or short name; several may be comma-separated (up to 10). Omit it to search the whole market
  • keyword (optional): words that must appear in the title, such as 回购 (share repurchase)
  • categories (optional): announcement categories, see the table below
  • start_date / end_date (optional): YYYY-MM-DD, Beijing time, inclusive
  • market (optional): board filter for market-wide searches. sh Shanghai, shmb Shanghai main board, shkcp STAR Market, sz Shenzhen, szmb Shenzhen main board, szcy ChiNext, bj Beijing Stock Exchange
  • source (optional): announcements (default) or investor_relations (records of investor meetings and site visits)
  • sort (optional): newest (default) or oldest
  • limit (optional): default 30, maximum 200
  • offset (optional): position to continue from

The result includes total (the number of matches). When there are more results it also includes next_offset, which is passed as offset in the next call.

Read ​

read_document ​

Read the text of an announcement or report (PDF, or HTML for older filings). The result is plain text.

  • url (required): a document URL returned by list_reports or search_announcements
  • pages (optional): page ranges, such as 5, 10-20, 1-3,8
  • query (optional): words to locate inside the document, space-separated; any match counts
  • max_chars (optional): output limit in characters, default 20000

Three modes:

  1. url only: page count, table of contents and the opening pages.
  2. With query: the matching pages with snippets, to locate a section in a long report.
  3. With pages: the full text of those pages. If it exceeds max_chars, the result ends with the pages value to continue from.

Structured data ​

Shanghai, Shenzhen and Beijing listings only.

get_financials ​

  • stock (required)
  • statements (optional): indicators (key ratios), income, balance, cashflow; several may be requested, default indicators
  • period (optional): annual (default), semiannual, q1, q3. Quarterly and semi-annual figures are cumulative year-to-date
  • periods (optional): number of recent periods, default 5 (the upstream source provides at most 5)

Statement amounts are in units of 10,000 CNY (万元) and are the condensed figures from CNINFO's company pages (main line items). For complete line items, read the report itself with read_document.

Download ​

download_reports ​

Save periodic reports or prospectuses as PDF files in the download directory. The selection is the same as list_reports (full reports only).

  • stock (required)
  • report_type (optional): default annual
  • year (optional): omit to download every year
  • save_path (optional): a sub-directory inside the download root, such as annual/2024. Paths outside the root are rejected

download_documents ​

  • urls (required): a list of document URLs (up to 50)
  • save_path (optional): as above

Files are named code_name_title_announcementID.pdf. A file that already exists is not downloaded again. Each file is handled independently, and failures are listed one by one in failures.

Prompt templates ​

  • company_research: an in-depth research brief on a listed company
  • earnings_review: a review of the latest periodic report

Partial results ​

Results that involve several upstream requests carry a complete field. If some pages, datasets or files fail, what was retrieved is still returned, complete is false, and warnings or errors describe what is missing.

Command line:

bash
npx -y @youhaozhao/cninfo-mcp            # start the MCP server (stdio)
npx -y @youhaozhao/cninfo-mcp probe      # online self-test: announcement query, financial data, document reading
npx -y @youhaozhao/cninfo-mcp selftest   # offline self-test: is the installation itself (PDF text extraction) working

Coverage and limits ​

  • Announcement search: companies listed in Shanghai, Shenzhen and Beijing (including B shares) and Hong Kong announcements; announcements of funds and bonds can be searched by code.
  • list_reports, get_financials, get_company_data: Shanghai, Shenzhen and Beijing listings.
  • Announcements are searched by title keyword. There is no full-text search across announcements; inside a single document, keywords can be located with query.
  • Scanned documents (some older filings) have no text layer and cannot be read as text.
  • No real-time quotes or price history.
