A 股 MCP 服务器怎么选：行情、财务数据与披露文件 ​

给 AI 助手接入 A 股数据的 MCP 服务器已经有不少，名字相近，能力却差别很大。区分它们最有效的办法是看数据从哪里来：数据来源决定了能查什么、要不要注册、稳不稳定。

本文按数据来源把它们分成两大类：行情与数据类，披露文件类。信息截至 2026 年 11 月，各项目的具体功能请以它们自己的文档为准。

先看你要回答什么问题 ​

你想问 AI 的问题需要的数据该用哪一类
这只股票最近三个月走势如何？均线和成交量怎么样？行情、K 线、技术指标行情与数据类
按市盈率和净资产收益率筛选一批公司全市场的结构化指标行情与数据类
年报里管理层怎么解释毛利率下滑？年报正文披露文件类
过去一个月哪些公司发布了业绩预告？公告披露文件类
招股书里的募投项目现在进展如何？招股书和年报正文披露文件类
最近几次机构调研都问了什么？投资者关系活动记录披露文件类

行情与数据类 ​

这一类服务器把现成的金融数据接口包装成 MCP 工具，长处是行情、K 线和大范围的结构化数据。常见的数据来源有三个。

BaoStock ​

免费，不需要注册。以历史 K 线、财务指标和宏观数据为主。代表项目有 a-share-mcp-is-just-i-need。

AKShare ​

开源的金融数据接口库，数据取自多个公开网站，覆盖面广，除 A 股外也包括港股、美股、基金和期货等。由于依赖的是公开网页，接口会随上游网站变化，也可能被限频。代表项目有 akshare-one-mcp。

Tushare ​

数据比较规整，覆盖股票、基金、债券和宏观等。需要注册并获取 token，部分接口有积分要求。代表项目有 FinanceMCP。

这几类服务器大多用 Python 编写，需要相应的运行环境。

披露文件类：cninfo-mcp ​

cninfo-mcp 的数据来自巨潮资讯网，也就是中国证监会指定的上市公司信息披露网站。它处理的是公司披露的文件本身：

  • 检索公告：按公司、标题关键字、26 个分类、板块和日期筛选，支持全市场检索。
  • 列出并阅读定期报告和招股书：年报、半年报、季报、招股说明书。
  • 直接读取 PDF 正文：先看目录，再按关键字定位，按页读取，回答可以标注页码。
  • 取巨潮个股页上的结构化数据：财务指标、三张报表、股东、分红、质押、解禁等。
  • 下载 PDF 到本地。

它不提供实时行情、K 线和技术指标。运行只需要 Node.js，不需要 Python 和 API Key。

组合使用 ​

两类服务器并不冲突，可以同时接入同一个客户端。一个常见的组合是：一个行情与数据类服务器负责行情和筛选，cninfo-mcp 负责读文件和核实。

先筛出近三年净资产收益率都高于 15% 的白酒公司，再到它们最新的年报里，看管理层怎么描述行业趋势，标注页码。

第一步由行情与数据类服务器完成，第二步交给 cninfo-mcp。AI 助手会根据问题自己选择用哪个服务器的工具。

选择时要看的几件事 ​

  • 数据来源是否说明清楚。来源决定了数据的口径、更新时间和使用条款。
  • 是否仍在维护。上游接口经常变化，长期不更新的项目容易失效。
  • 需要什么凭据。需要 token 的服务，要确认配置方式和额度。
  • 对上游是否克制。会不会因为并发过高被上游限流，甚至封禁 IP。
  • 权限边界。服务器会访问哪些网站、会不会写本地文件，文档里应该写明。cninfo-mcp 的说明见安全边界。
