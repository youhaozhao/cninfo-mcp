巨潮资讯 MCP 服务器让 AI 直接查公告、读年报、取财务数据

cninfo-mcp 是面向 A 股投研的开源 MCP 服务器。接入之后，Claude、Cursor 等 AI 助手可以在巨潮资讯网上检索公告、阅读年报和招股书正文、获取财务与股东数据。覆盖沪、深、北三家交易所，港股公告也可检索。

Claude Code

$claude mcp add cninfo -- npx -y @youhaozhao/cninfo-mcp

只需 Node.js 22.13+，不需要 Python，也不需要 API Key

其他客户端的安装方法 在 GitHub 上查看

怎么用

装好之后，直接提问

不用记工具名和参数。用自然语言说出要查什么，AI 助手会自己选择工具并组合调用。

  • 贵州茅台 2025 年年报里，管理层怎么看明年的行业趋势？

    list_reports→read_document

    找到年报，按关键字定位到相关章节，只读那几页。

  • 对比宁德时代近五年的收入、净利润、经营现金流和 ROE

    get_financials

    一次取回主要指标、利润表和现金流量表的最近五期。

  • 过去一个月创业板有哪些公司发布了业绩预告？

    search_announcements

    不指定公司就是全市场检索，可按分类、板块和日期筛选。

  • 下载 688981 的招股书

    download_reports

    PDF 保存到下载目录，文件名带代码、简称和标题。

  • 茅台最近几期的十大股东和股东人数有什么变化？

    get_company_data

    一次请求多个数据集：十大股东、股东人数、分红、质押等。

  • 宁德时代最近几次机构调研都聊了什么？

    search_announcements→read_document

    检索投资者关系活动记录，再读取记录正文。

工具

八个工具，覆盖一条完整的研究链路

从找到公司、找到文件，到读正文、取数据、存档。

查找与检索

search_securities只读
按代码、简称或拼音首字母查找证券。
list_reports只读
列出年报、半年报、季报或招股书，返回标题、披露日期和 PDF 地址。
search_announcements只读
按公司、标题关键字、分类、日期、板块检索公告；不指定公司即全市场检索，也可查调研记录。

阅读

read_document只读
阅读公告或报告正文，支持目录概览、关键字定位、按页读取。

结构化数据

get_financials只读
主要指标、利润表、资产负债表、现金流量表（最近五期）。
get_company_data只读
公司概况、十大股东、股东人数、分红、质押、解禁、融资融券、大宗交易、龙虎榜等 15 个数据集。

下载

download_reports写入下载目录
把定期报告或招股书的 PDF 保存到下载目录。
download_documents写入下载目录
按地址把指定公告保存到下载目录。

另有两个提示词模板：company_research（上市公司深度研究）和 earnings_review（最新财报解读）。 查看全部参数、公告分类和数据集 →

设计取舍

为投研场景做的几个决定

  • 读的是一手披露文件

    数据直接来自巨潮资讯网，中国证监会指定的上市公司信息披露网站。AI 读到的是公司披露的原文，回答可以标注报告名称和页码，方便核对。

  • 读得动上百页的年报

    read_document 先给出页数和目录，再按关键字定位、按页读取。不必把整份 PDF 塞进上下文，也不需要先下载再上传。

  • 一条命令装好

    只依赖 Node.js。不需要 Python 环境、API Key、账号或积分；发布包自带全部依赖，安装时不再拉取其他包。

  • 对上游保持克制

    巨潮会对高并发请求返回 403 并短暂封禁 IP。服务器对所有请求统一限速，被限流时自动冷却重试，读过的文档落盘缓存。

  • 结果不完整就明说

    部分分页、部分数据集或部分文件失败时，已取得的内容照常返回，并用 complete: false 标出，不会把残缺结果当作完整结果。

  • 边界清楚

    只访问巨潮资讯网的两个 HTTPS 主机，只在下载目录内写文件，不需要也不读取任何凭据。每个工具都声明了只读或写入注解。

数据范围

覆盖什么，不覆盖什么

可以做到

  • 公告检索沪、深、北交所上市公司（含 B 股）和港股公告；基金、债券可按代码检索。

  • 定期报告与招股书年报、半年报、一季报、三季报、招股说明书。

  • 正文阅读PDF 正文，以及早期的 HTML 公告。

  • 结构化数据财务指标与三张报表、15 个公司数据集（沪、深、北交所上市公司）。

不在范围内

  • 实时行情和 K 线

  • 跨公告的全文检索（公告按标题关键字检索，单个文档内可以按关键字定位）

  • 扫描件的正文（部分早期公告没有文本层）

需要行情和技术指标时，可以搭配其他数据源的 MCP 服务器一起用。 A 股 MCP 服务器怎么选 →

安装

一分钟接入

任何支持 MCP（stdio）的客户端都可以用。下面是几个常见客户端的写法。

$claude mcp add cninfo -- npx -y @youhaozhao/cninfo-mcp

设置 → 开发者 → 编辑配置，加入以下内容后重启客户端。

{
  "mcpServers": {
    "cninfo": {
      "command": "npx",
      "args": ["-y", "@youhaozhao/cninfo-mcp"]
    }
  }
}

写入 ~/.cursor/mcp.json（全局）或项目里的 .cursor/mcp.json。

{
  "mcpServers": {
    "cninfo": {
      "command": "npx",
      "args": ["-y", "@youhaozhao/cninfo-mcp"]
    }
  }
}
$code --add-mcp '{"name":"cninfo","command":"npx","args":["-y","@youhaozhao/cninfo-mcp"]}'
$codex mcp add cninfo -- npx -y @youhaozhao/cninfo-mcp

Cherry Studio、Trae、Cline、Windsurf 等：命令填 npx，参数填 -y 和包名，或导入这段 JSON。

{
  "mcpServers": {
    "cninfo": {
      "command": "npx",
      "args": ["-y", "@youhaozhao/cninfo-mcp"]
    }
  }
}

想先确认本机能连上巨潮，可以运行自检：

$npx -y @youhaozhao/cninfo-mcp probe

常见问题

开始之前

cninfo-mcp 是巨潮资讯网的官方产品吗？

不是。它是社区维护的开源项目，与巨潮资讯网的运营方深圳证券信息有限公司没有隶属、合作或授权关系。工具调用的是巨潮资讯网网页自身使用的查询接口，不是官方数据服务接口，可能随时变更或限流。

需要 API Key、账号或付费吗？

都不需要。cninfo-mcp 以 MIT 许可证开源，只依赖 Node.js 22.13 及以上版本，不需要 Python，也不读取任何账号、Cookie 或密钥。

支持哪些 AI 客户端？

任何支持 MCP（stdio 传输）的客户端都可以接入，例如 Claude Code、Claude Desktop、Cursor、VS Code、Codex CLI、Cherry Studio、Trae、Cline 和 Windsurf。

能查实时行情或 K 线吗？

不能。cninfo-mcp 专注披露文件和基本面数据：公告、定期报告、招股书、财务报表、股东与交易披露。需要行情时，可以搭配其他数据源的 MCP 服务器一起使用。

数据准确吗？

公告和报告是上市公司披露的原文。结构化的财务数据是巨潮个股页的精简口径，可能与报告原文存在口径差异，重要数字请以披露文件为准。工具不对内容的准确性、完整性和时效性作保证，也不构成投资建议。

可以批量下载年报吗？

可以。让 AI 调用 download_reports 并省略年份，就会下载一家公司全部年份的年报全文。请保持默认的并发限制，不要做高频或大批量抓取：巨潮资讯网会对大量并发请求返回 403，并短暂封禁 IP。
