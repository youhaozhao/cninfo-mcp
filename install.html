安装与配置 ​

cninfo-mcp 以 npm 包 @youhaozhao/cninfo-mcp 发布，通过 npx 启动，使用 stdio 传输。任何支持 MCP 的客户端都可以接入，下面按客户端给出写法。

准备：Node.js 22.13+ ​

唯一的依赖是 Node.js 22.13 或更高版本。不需要 Python，也没有其他要另外安装的东西。

bash
node -v   # 应输出 v22.13.0 或更高

版本过低时，到 nodejs.org 下载 LTS 版本，或者用 nvm、fnm 等版本管理器升级。

下载慢？

npx 第一次运行时要从 npm 下载这个包（解压后约 7 MB，自带全部依赖）。网络不稳定时，可以先把 npm 切换到镜像源：

bash
npm config set registry https://registry.npmmirror.com

按客户端安装 ​

Claude Code ​

bash
claude mcp add cninfo -- npx -y @youhaozhao/cninfo-mcp

默认只对当前项目生效。想在所有项目里使用，加上 --scope user：

bash
claude mcp add --scope user cninfo -- npx -y @youhaozhao/cninfo-mcp

装好之后在 Claude Code 里输入 /mcp，可以看到 cninfo 的连接状态和工具列表。

原生 Windows（非 WSL）

在原生 Windows 上，用 npx 启动的本地 MCP 服务器需要用 cmd /c 包一层：

bash
claude mcp add cninfo -- cmd /c npx -y @youhaozhao/cninfo-mcp
作为 Claude Code 插件安装

cninfo-mcp 也收录在 china-fin-toolkit 插件市场里，可以和其中的技能一起安装：

txt
/plugin marketplace add youhaozhao/china-fin-toolkit
/plugin install cninfo-mcp@china-fin-toolkit

Claude Desktop ​

打开「设置 → 开发者 → 编辑配置」，在配置文件里加入以下内容，然后重启客户端。配置文件位于：

  • macOS：~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows：%APPDATA%\Claude\claude_desktop_config.json
json
{
  "mcpServers": {
    "cninfo": {
      "command": "npx",
      "args": ["-y", "@youhaozhao/cninfo-mcp"]
    }
  }
}

Cursor ​

把下面的内容写入 ~/.cursor/mcp.json（全局），或项目根目录下的 .cursor/mcp.json（只对该项目生效）：

json
{
  "mcpServers": {
    "cninfo": {
      "command": "npx",
      "args": ["-y", "@youhaozhao/cninfo-mcp"]
    }
  }
}

VS Code ​

用命令行添加：

bash
code --add-mcp '{"name":"cninfo","command":"npx","args":["-y","@youhaozhao/cninfo-mcp"]}'

或者在工作区的 .vscode/mcp.json 里写入（注意 VS Code 的键名是 servers）：

json
{
  "servers": {
    "cninfo": {
      "command": "npx",
      "args": ["-y", "@youhaozhao/cninfo-mcp"]
    }
  }
}
添加到 VS Code

Codex CLI ​

bash
codex mcp add cninfo -- npx -y @youhaozhao/cninfo-mcp

等价于在 ~/.codex/config.toml 里加入：

toml
[mcp_servers.cninfo]
command = "npx"
args = ["-y", "@youhaozhao/cninfo-mcp"]

Gemini CLI ​

在 ~/.gemini/settings.json（或项目内的 .gemini/settings.json）里加入通用配置中的 mcpServers 一段。

Cherry Studio ​

打开「设置 → MCP 服务器 → 添加服务器」，类型选择 STDIO，命令填 npx，参数每行一个：

txt
-y
@youhaozhao/cninfo-mcp

也可以选择从 JSON 导入，粘贴下面的通用配置。

Trae ​

在 MCP 管理页选择「添加 → 手动配置」，粘贴下面的通用配置。

OpenClaw ​

bash
openclaw mcp add cninfo --command npx --arg -y --arg @youhaozhao/cninfo-mcp
openclaw mcp doctor cninfo --probe

按 OpenClaw 文档的说明，增删已保存的服务器之前需要先停止本地 Gateway，改完再启动。

其他客户端（通用配置） ​

Cline、Windsurf、Zed 等客户端的配置文件位置各不相同，但内容都是同一段：命令 npx，参数 -y 和包名。

json
{
  "mcpServers": {
    "cninfo": {
      "command": "npx",
      "args": ["-y", "@youhaozhao/cninfo-mcp"]
    }
  }
}

验证安装 ​

想先确认本机能连上巨潮资讯网，可以运行联网自检。它会实际查询沪、深、北交所的年报，调用一次财务数据接口，并读取一份文档：

bash
npx -y @youhaozhao/cninfo-mcp probe
txt
[OK  ] 年报查询 沪市 SSE: 600519=27
[OK  ] 年报查询 深市 SZSE: 000001=25
[OK  ] 年报查询 北交所 BSE: 920185=5
[OK  ] 财务数据 data20: 3 periods, 6 rows
[OK  ] 文档读取 static: 贵州茅台2026年第三季度报告: 12 pages, 11065 chars

全部探测通过。

另有一个不联网的自检，只检查安装本身（PDF 文本提取）是否可用：

bash
npx -y @youhaozhao/cninfo-mcp selftest

然后在客户端里试一句：

查一下贵州茅台最新的年报，告诉我一共多少页、目录里有哪些章节。

配置 ​

全部通过环境变量设置，都可以省略。

环境变量说明默认值
CNINFO_MCP_DOWNLOAD_DIR下载根目录，下载工具只能写入这个目录~/Downloads/cninfo-mcp
CNINFO_MCP_CACHE_DIR证券列表、已读取文档及其文本的缓存目录系统缓存目录下的 cninfo-mcp
CNINFO_MCP_CACHE_MAX_MB文档缓存上限，超出后淘汰最久未使用的文件1024
CNINFO_MCP_CONCURRENCY同时向巨潮发起的请求数（1–8）4

在 JSON 配置里用 env 字段设置：

json
{
  "mcpServers": {
    "cninfo": {
      "command": "npx",
      "args": ["-y", "@youhaozhao/cninfo-mcp"],
      "env": {
        "CNINFO_MCP_DOWNLOAD_DIR": "/Users/me/Research/filings"
      }
    }
  }
}

Claude Code 用 --env（选项要写在服务器名称之前）：

bash
claude mcp add --env CNINFO_MCP_DOWNLOAD_DIR=/Users/me/Research/filings cninfo -- npx -y @youhaozhao/cninfo-mcp

其余选项（请求超时、调试日志）见工具与配置参考。

不建议调高并发

巨潮资讯网会对短时间内的大量请求返回 403，并暂时封禁 IP。服务器已经对所有上游请求统一限速，被限流时自动冷却重试，保持默认值即可。原理见性能与稳定性。

升级与卸载 ​

  • 查看版本：npx -y @youhaozhao/cninfo-mcp --version
  • 升级：npx 可能继续使用本机已缓存的旧版本。把配置里的包名写成 @youhaozhao/cninfo-mcp@latest，每次启动都会使用最新发布的版本。
  • 从 2.x 及更早版本升级：3.0 是一次不兼容升级，工具名称和参数有变化，见升级指南。
  • 卸载：从客户端配置里删除 cninfo 一项（Claude Code 运行 claude mcp remove cninfo）。下载目录和缓存目录可以手动删除。

安装时的常见问题 ​

启动后客户端提示连接失败 ​

先确认 node -v 不低于 22.13。图形界面客户端（如 Claude Desktop）有时读不到终端里配置的 Node 路径，可以把 command 改成 npx 的绝对路径（macOS 和 Linux 上用 which npx 查看，Windows 上用 where npx）。

查询时报 403 或提示被限流 ​

这是巨潮资讯网的限流。服务器会自动冷却后重试，通常等待片刻即可恢复。不要调高 CNINFO_MCP_CONCURRENCY，也不要同时开多个客户端并发查询。

文档读出来是空的 ​

部分早期公告是扫描件，没有文本层，无法读出正文。read_document 会在结果里给出提示。

更多问题见常见问题，或在 GitHub Issues 反馈。
